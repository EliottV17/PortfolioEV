# Eliott Velarde — Portfolio

Este repositorio contiene el código de mí portfolio: un sitio estático bilingüe (inglés y español) que presenta su perfil, experiencia y proyectos.

La interfaz está inspirada en terminales y Neovim, y está construida con Astro, TypeScript y Tailwind CSS. El sitio ya está desplegado; este repositorio documenta y contiene su implementación.
